CSS (Cascading Style Sheets)

CSS is used to style and design web pages.

Ways of Adding CSS to a Webpage:

1) Inline CSS
   - CSS is written directly inside an HTML tag using the "style" attribute.

2) Internal CSS
   - CSS is written inside a <style> tag within the <head> section of an HTML document.

3) External CSS
   - CSS is written in a separate .css file and linked to the HTML file using the <link> tag.


syntax

   <!-- Inline CSS -->
    <h1 style="color: red;">Hello</h1>

    <!-- Internal CSS: put inside <head> -->
    <style>
    p {
        color: blue;
    }
    </style>

    <!-- External CSS: put inside <head> -->
    <link rel="stylesheet" href="style.css">

Property
========================
A CSS Property is an attribute that specifies 
which aspect of an HTML element you want to style or change,
such as its color, size, font or background.

========================

========================
Selector --> Property --> Value 
   p tag    -->  Color   --> #ffa088 (Pastel Coral)

- Property: What do I want to change?
- Value: What should I change it to?

========================
CSS COLOR Property
========================

4 ways to write color

1) Color Names

- Use predefined color names.
- Examples: white, black, red, green.

2) HEX (Hexadecimal)

- Uses hexadecimal values to represent colors.
- Examples: #ffffff (white), #000000 (black), #808080 (gray).
- Useful for specifying precise colors.

3) RGB / RGBA

- RGB stands for Red, Green, Blue.
- Each color value ranges from 0 to 255.
- Examples: rgb(255, 0, 0) (red), rgb(175, 236, 190).
- RGBA adds an alpha value for transparency.
- Example: rgba(255, 0, 0, 0.3) (red with 30% opacity).

4) HSL / HSLA

- HSL stands for Hue, Saturation, Lightness.
- Hue represents the color, saturation its intensity, and lightness how light or dark it is.
- Example: hsl(120, 100%, 50%) (green).
- HSLA adds an alpha value for transparency.

========================
CSS FONT PROPERTIES
========================

-->CSS font properties control the appearance of text, including its typeface, size, thickness, and styling

1) font-family 
- Specifies which typeface is used for text.
- Examples: Arial, Verdana, Times New Roman.
- Multiple fonts can be provided as fallbacks.

**2. `font-size`**
- Controls the size of the text.
- Common units: `px`, `em`, `rem`, `%`.
- Example value: `16px`.

**3. `font-weight`**
- Controls the thickness or boldness of text.
- Common values: `normal`, `bold`, `100`–`900`.
- Example value: `700`.

**4. `font-style`**
- Controls whether text is normal, italic, or oblique.
- Common values: `normal`, `italic`, `oblique`.

**5. `font-variant`**
- Controls certain font variations, commonly small capitals.
- Common value: `small-caps`.

**6. `line-height`**
- Controls the height of each line of text, affecting the spacing between lines.
- Common values: `1.5`, `24px`.

**7. `font` (shorthand property)**
- Allows multiple font settings to be specified in one declaration.
- Can combine font style, weight, size, line height, and family in a single rule.
