Class and ID

1. ID:
   - Used to uniquely identify a specific HTML element.
   - An ID should be unique within a page.
   - In CSS, an ID is selected using #.

2. CLASS:
   - Used to group HTML elements.
   - Multiple elements can share the same class.
   - In CSS, a class is selected using .

3. Difference:
   - ID: identifies a specific element.
   - CLASS: groups elements for styling or selection.
