Events in JS

The Change in the state of an object is known as an Event

Events are Fired to notify code of "intersting changes" that may affect code execution.

  • Mouse Events (Click, double click etc..)
  • Keyboard events (keypress, keyup, keydown, etc..)
  • Form events (submit)
  • Print events & many more

Event Object

Events Objects are the special objects that has details abouot the event

All Event handalers have access to the event object's properties and methods.
